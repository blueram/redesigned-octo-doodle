# MiniGame V4.0 안정화 버전

## 포함 게임
- 초성게임
- OX 이동게임
- 포트리스

## V4.0 주요 개선
- 전적용 사용자 ID, 기기 ID, 접속 세션 ID 분리
- 같은 탭 새로고침 시 기존 세션 복구
- 새 탭/다른 기기는 별도 참가자로 처리
- Firebase Transaction으로 2명 정원 동시 입장 보호
- 10초 Heartbeat와 35초 비활성 세션 정리
- Firebase onDisconnect로 종료된 참가자 자동 제거
- 방장 접속이 사라지면 남은 참가자에게 방장 자동 승계
- OX 첫 판 선공 무작위, 다음 판은 직전 패자 선공
- 포트리스 첫 판 선공 무작위, 다음 판은 직전 패자 선공
- 포트리스 10가지 지형 썸네일 선택
- 온라인 포트리스는 두 사람 선택 중 하나를 무작위 적용
- 궤적 아이템 상태 및 가시성 개선
- PC/온라인 전적 분리

## 온라인 테스트 권장
- 서로 다른 휴대전화 2대로 테스트
- 같은 휴대전화 테스트 시 새 탭은 별도 세션으로 처리
- 같은 탭 새로고침은 기존 참가자로 복구


## V4.1 초성퀴즈 개선
- 초성퀴즈 온라인 방 최대 4명 접속 (OX/포트리스는 기존 2명 유지)
- 2명 이상 및 참가자 준비 완료 시 방장 시작
- 입력창 바로 위에 1~4위 실시간 순위 고정 배치
- Firebase Transaction으로 동시 정답 중 최초 1명만 인정
- 정답자와 정답을 3초간 공개한 뒤 다음 문제 자동 진행
- 정답 공개 중 입력 잠금, 중간 퇴장 시 남은 참가자 순위 자동 재정렬
- 최종 결과에 전체 참가자 순위와 점수 표시
