# MiniGame 3종 PC 버전

## 구성
1. OX 이동식 게임: 3개의 말을 놓은 뒤 인접 칸으로 이동하며 PC와 대전
2. 초성 퀴즈: 무작위 10문제
3. 포트리스 PC 대전
   - 탱크 좌우 이동
   - 버튼 짧게 누르기: 1단계
   - 버튼 길게 누르기: 계속 1단계씩 조절
   - 더블클릭/더블탭 확대 방지
   - PC AI는 무작위로 정해진 5~10번째 발 안에 조준을 완성

## 실행 방법
- index.html을 더블클릭해 실행합니다.
- PWA 캐시까지 정상 사용하려면 GitHub Pages 또는 로컬 웹서버에서 실행하세요.
- GitHub 저장소에는 ZIP을 풀어 파일 전체를 그대로 업로드하면 됩니다.
