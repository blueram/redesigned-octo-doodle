# MiniGame 3종 PC 버전

## 구성
1. OX 이동식 게임: 내 말 3개를 놓은 뒤 선택한 말을 비어 있는 어느 칸으로든 이동하며 PC와 대전
2. 초성 퀴즈: 무작위 10문제
3. 포트리스 PC 대전
   - 탱크 좌우 이동
   - 버튼 짧게 누르기: 1단계
   - 버튼 길게 누르기: 계속 1단계씩 조절
   - 더블클릭/더블탭 확대 방지
   - PC AI는 무작위로 정해진 5~10번째 발 안에 조준을 완성
   - 내 포탄에 PC 탱크가 명중하면 좌우 방향과 45~160px 이동 거리를 랜덤으로 정해 이동
   - 포탄이 떨어진 지형은 분화구 형태로 파임
   - 시작 지형은 급경사가 적은 완만한 산 지형이며 시작 지점은 부드럽게 평탄화

## 실행 방법
- index.html을 더블클릭해 실행합니다.
- PWA 캐시까지 정상 사용하려면 GitHub Pages 또는 로컬 웹서버에서 실행하세요.
- GitHub 저장소에는 ZIP을 풀어 파일 전체를 그대로 업로드하면 됩니다.
