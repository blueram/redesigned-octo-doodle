## 게임
- 초성게임: 혼자 10문제 타임어택 / 온라인 10점 선승
- OX: 혼자 PC / 온라인 1:1 / 3선승
- 포트리스: 혼자 PC / 온라인 1:1 / 3선승

## V2.2 수정
- OX: 각자 3개 배치 후 자기 말을 선택해 빈칸으로 이동
- 초성게임: 규칙과 예시 설명 추가
- 포트리스: 탱크 방향 고정, 좌우 이동, 각도/파워 분리
- 모든 조절 버튼 길게 누르기 지원
- PC는 무작위 5~10발 주기로 명중하도록 조정
- 더블 클릭 확대 방지

## V2.3 초성 힌트 개선
- 문제 시작 시 1단계 힌트 즉시 표시
- 3초 동안 정답이 없으면 2단계 힌트
- 추가 3초 동안 정답이 없으면 3단계 힌트
- 다음 문제로 넘어가거나 종료되면 기존 힌트 타이머 자동 초기화

## V2.4 온라인 초성 반복 오류 수정
- 같은 라운드의 Firebase 상태 변경 시 문제와 힌트를 반복 재생하지 않음
- 다음 문제 전환 예약을 방장 1회로 제한
- 라운드 토큰을 사용해 중복 화면 갱신 차단
- 직전 문제와 같은 단어가 연속으로 나오지 않도록 개선
- 10점 도달 후 문제 생성 중단

## V2.5 초성게임 UI 및 입력 개선
- 정답과 오답 모두 제출 후 입력창 자동 초기화
- 온라인 점수판을 문제 위쪽에 고정
- 내 점수와 상대 점수를 항상 표시
- 힌트 글자 크기 확대
- 1·2·3단계 힌트를 5초 간격으로 계속 반복 순환

## V2.6 버전 표시
- 모든 게임 화면 오른쪽 상단에 현재 버전 표시
- 표시 버전: MiniGame V2.6

## V2.7 OX 3개 제한 보강
- 각 플레이어의 말은 어떤 상황에서도 최대 3개만 유지
- 온라인 이동은 Firebase 트랜잭션으로 처리하여 동시 입력 충돌 방지
- 새 위치에 놓기 전에 기존 말을 먼저 제거
- 서버에서 4개 이상 상태가 들어와도 자동으로 3개로 정리

## V2.8 온라인 OX 상대 말 삭제 오류 수정
- 전체 보드 덮어쓰기를 중단하고 한 번의 이동만 Firebase 트랜잭션으로 반영
- 출발 위치가 현재 서버에서도 본인 말인지 확인
- 도착 위치가 빈칸인지 확인하여 상대 말 삭제 차단
- 상대방과 동시에 눌러도 잘못된 이동은 취소 후 다시 선택
